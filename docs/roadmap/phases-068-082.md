# Milestone M8: Differential Validation and Interoperability (Historical — Retired)

> [!WARNING]
> **SUPERSEDED / RETIRED — NOT THE ACTIVE DEVELOPMENT PLAN**
> The milestone and phases detailed in this document have been **retired** and are no longer active planned work.
> QCC development is currently paused after the integrated compilation pipeline checkpoint (Phase 59).
> Future development priorities and the next roadmap will be determined separately (TBD).
> This document is preserved strictly as a historical planning and architectural design reference.

> **Milestone Code**: `M8` | **Phases Covered**: 68–82 | **Status**: Retired

## Scope Summary
Differential testing with Qiskit Aer, Cirq, and Stim; unified test harness; provider-neutral backend API; OpenQASM execution artifacts; optional IBM/Braket/provider adapters; and preflight checks.

## Phase 068 — Qiskit Aer differential testing

| Attribute | Specification |
|---|---|
| **Phase Number** | **Phase 68** |
| **Exact Phase Title** | Qiskit Aer differential testing |
| **Milestone** | Milestone M8: Differential Validation and Interoperability (`M8`) |
| **Relative Engineering Effort** | **L** |
| **Source Document Page** | Page 34 (`QCC_Quantum_Circuit_Compiler_Engineering_Roadmap(1).docx`) |

### 1. Objective
Compare QCC against an independent general-purpose quantum simulator.

### 2. Required Concepts & Background
Statevector semantics, OpenQASM conversion, endianness normalization and version pinning.

### 3. Prerequisites & Dependencies
Phases 11, 26 and 67.

### 4. Ordered Implementation Tasks
1. Create an optional reference Python environment.
2. Pin Qiskit/Aer versions.
3. Generate common circuit fixtures.
4. Run QCC and Aer on unitary circuits.
5. Compare statevectors up to one common phase after ordering conversion.
6. Compare terminal measurement distributions with statistical tests.
7. Save minimized failing examples.

### 5. Expected Files and Modules
```text
tools/reference/qiskit/; tests/differential/qiskit.rs; tests/fixtures/differential/.
```

### 6. Required Tests
Single/two-qubit gates; Bell/GHZ; rotations; random small circuits; measurement distributions.

### 7. Definition of Done
Reference comparisons are reproducible and independent of QCC simulator code.

### 8. Failure Modes & Debugging Considerations
Endian mismatch; different gate convention; simulator version drift.

### 9. Explicit Exit Gate
> **EXIT GATE**: Shared gate-set corpus passes or discrepancies are isolated and documented.
