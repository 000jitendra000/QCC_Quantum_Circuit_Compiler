# Milestone M4: Generic Target and Basis Translation

> **Milestone Code**: `M4` | **Phases Covered**: 37–43

## Scope Summary
Define target hardware models, capability queries, fixed decomposition templates, native single-qubit synthesis, recursive basis translation, direction correction, and final legality validation.

---

## Phase 037 — Generic Target data model

| Attribute | Specification |
|---|---|
| **Phase Number** | **Phase 37** |
| **Exact Phase Title** | Generic Target data model |
| **Milestone** | Milestone M4: Generic Target and Basis Translation (`M4`) |
| **Relative Engineering Effort** | **L** |
| **Source Document Page** | Page 21 (`QCC_Quantum_Circuit_Compiler_Engineering_Roadmap(1).docx`) |

### 1. Objective
Describe hardware without a fixed vendor-specific basis.

### 2. Required Concepts & Background
Target operations, qubit capacity, parameter domains, directionality and optional properties.

### 3. Prerequisites & Dependencies
Phases 24–25 and 36.

### 4. Ordered Implementation Tasks
1. Define target identity and qubit count.
2. Define supported operation descriptors and arities.
3. Define parameter domains and allowed physical operand tuples.
4. Represent per-operation directed/undirected connectivity.
5. Add optional timing and calibration fields with provenance.
6. Serialize target descriptions.

### 5. Expected Files and Modules
```text
qcc-target/src/{target,operation,connectivity,calibration}.rs; tests/target/.
```

### 6. Required Tests
Synthetic CX, CZ, ECR and mixed targets; invalid arity and topology references.

### 7. Definition of Done
Different target families can be described without compiler-core changes.

### 8. Failure Modes & Debugging Considerations
Hardcoded IBM basis; treating missing calibration as zero error.

### 9. Explicit Exit Gate
> **EXIT GATE**: Synthetic target fixtures validate correctly.

## Phase 039 — Fixed decomposition template library

| Attribute | Specification |
|---|---|
| **Phase Number** | **Phase 39** |
| **Exact Phase Title** | Fixed decomposition template library |
| **Milestone** | Milestone M4: Generic Target and Basis Translation (`M4`) |
| **Relative Engineering Effort** | **L** |
| **Source Document Page** | Page 22 (`QCC_Quantum_Circuit_Compiler_Engineering_Roadmap(1).docx`) |

### 1. Objective
Implement verified known templates before arbitrary two-qubit synthesis.

### 2. Required Concepts & Background
Circuit identities, CX/CZ transformations, SWAP and Toffoli.

### 3. Prerequisites & Dependencies
Phases 10, 27, 31 and 37.

### 4. Ordered Implementation Tasks
1. Implement SWAP = CX(a,b); CX(b,a); CX(a,b).
2. Implement CX↔CZ with Hadamards on the correct target/control.
3. Choose one exact Toffoli template using H, T, Tdg and six CX.
4. Store operand order, phase contribution and preconditions.
5. Verify every template against independently built matrices.

### 5. Expected Files and Modules
```text
qcc-opt/src/synthesis/templates/{swap,cx_cz,toffoli}.rs; tests/synthesis/templates/.
```

### 6. Required Tests
All computational basis states; random superpositions; matrix equivalence; phase verification.

### 7. Definition of Done
Only mathematically verified decompositions enter the rule registry.

### 8. Failure Modes & Debugging Considerations
Claiming Toffoli from CX/CZ only; incorrect SWAP sequence; relative-phase Toffoli used as exact.

### 9. Explicit Exit Gate
> **EXIT GATE**: Template library passes full local matrix comparison.

### 1. Objective
Translate logical operations into target-supported operations.

### 2. Required Concepts & Background
Decomposition search, translation graphs, costs and recursion termination.

### 3. Prerequisites & Dependencies
Phases 37–40.

### 4. Ordered Implementation Tasks
1. Create a translation pass and rule registry.
2. Keep already-supported operations.
3. Find candidate decompositions for unsupported operations.
4. Recursively translate introduced gates with cycle/depth protection.
5. Select using configured cost and verify local equivalence.
6. Fail explicitly when no valid translation exists.

### 5. Expected Files and Modules
```text

```

### 6. Required Tests
CX, CZ, SWAP, Toffoli and rotations against synthetic targets; unsupported basis cases.

### 7. Definition of Done
Translator emits only operations in the target-compatible routing basis.

### 8. Failure Modes & Debugging Considerations
Recursive decomposition cycles; symbolic parameter loss; choosing invalid templates.

### 9. Explicit Exit Gate
> **EXIT GATE**: Translated circuits pass local equivalence and target operation checks.

1. Check gate identity and arity.
2. Check parameter domains.
3. Check physical qubit IDs and operand tuples.
