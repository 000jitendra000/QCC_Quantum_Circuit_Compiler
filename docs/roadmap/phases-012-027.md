# Milestone M2: Compiler Foundations and OpenQASM Frontend

> **Milestone Code**: `M2` | **Phases Covered**: 12–27

## Scope Summary
Establish deterministic pass manager, transactional DAG rewrite infrastructure, gate algebra, and robust OpenQASM 3 subset parsing and lowering into QccIR.
